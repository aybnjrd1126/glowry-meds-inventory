# Glowry Meds Pharma Inventory System

Java Swing + MySQL inventory, sales, and ordering system.

## Setup
1. Start XAMPP (Apache + MySQL)
2. Open phpMyAdmin, create a database named `inventory_db`
3. Import `database/inventory_db.sql` (Import tab in phpMyAdmin)
4. Open the project in NetBeans
5. Make sure the MySQL Connector/J library is added (see Libraries in project properties)
6. Run `LoginForm.java`

## Default accounts
- Admin: admin1 / admin123
- Staff: staff1 / staff123
